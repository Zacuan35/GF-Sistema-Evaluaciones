Tipography

Sistema tipográfico basado en las variables --fs-* de theme.scss.

Titulares / Montserrat

h1-h6 se eligen por jerarquía semántica del documento (un h1 por página, descendiendo sin saltos), nunca por el tamaño visual que se quiera lograr. Su tamaño en desktop (≥1024px) es el que se muestra abajo. Excepción documentada: en páginas de referencia densa con muchas subsecciones hermanas (ej. Buttons, Charts), el h2 usa class="text-lg" en vez de su tamaño natural — mismo nivel semántico, menor peso visual porque se repite muchas veces en una sola página.

Heading H1 --fs-3xl · 2.5rem

Heading H2 --fs-2xl · 2rem

Heading H3 --fs-xl · 1.75rem

Heading H4 --fs-lg · 1.5rem

Heading H5 --fs-md · 1.25rem
Heading H6 --fs-base · 1rem
<h1>Heading H1</h1>   /* var(--fs-3xl) */
<h2>Heading H2</h2>   /* var(--fs-2xl) */
<h6>Heading H6</h6>   /* var(--fs-base) */

Escala de texto .text-xs … .text-3xl

Mismas variables que usan h1-h6, pero como clases de tamaño puro: se aplican sobre cualquier etiqueta cuando el tamaño visual necesario no coincide con el nivel semántico del contenido. Por ejemplo, un <h3> que debe verse pequeño, o un <p> que debe destacar, sin cambiar de etiqueta.

.text-3xl 2.5rem

.text-2xl 2rem

.text-xl 1.75rem

.text-lg 1.5rem

.text-md 1.25rem

.text-base 1rem

.text-sm 0.875rem

.text-xs 0.75rem

<h3 class="text-sm">Un h3 que se ve pequeño</h3>
<p class="text-xl">Un párrafo que destaca</p>   /* la etiqueta la decide la semántica, la clase el tamaño */

Display / Montserrat, bold

Tamaños extra grandes para títulos destacados, como en una portada o sección hero. No son h1-h6 más grandes: son una voz tipográfica distinta que reutiliza el tope de la escala.

Jerarquía de contenido / ejemplo combinado

Cómo se ven juntos, en un mismo bloque de contenido, un encabezado de sección, su subtítulo, el lead, una descripción estándar y una descripción extensa. El encabezado usa Montserrat (--font-display); el subtítulo, el lead y las descripciones usan Roboto (--font-body), al ser todos etiquetas <p>.

Encabezado de sección 32px

Subtítulo 28px

Lead: un texto de introducción más grande que el párrafo estándar, usado para destacar la primera idea de una sección o dar contexto antes del contenido principal.

Texto de descripción estándar 14px. Este es el texto de cuerpo por defecto: descripciones cortas, ayudas y textos de apoyo dentro de una página.

Texto de descripción extensa 16px. Para bloques de lectura larga (contenido editorial, ayudas extensas, texto legal), usa .text-reading: sube el tamaño y el interlineado por encima de la descripción estándar para que un párrafo largo se siga leyendo cómodo.

<h2>Encabezado de sección</h2>
<p class="text-xl">Subtítulo</p>
<p class="lead">Lead</p>
<p>Descripción estándar</p>
<p class="text-reading">Descripción extensa</p>
